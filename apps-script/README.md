# Apps Script 백엔드 배포 방법

이 폴더의 `Code.gs`는 웹페이지가 데이터를 저장/조회할 때 쓰는 백엔드예요.
구글 스프레드시트가 아니라 구글 계정에 딸린 "스크립트 속성"이라는 간단한 저장공간을 씁니다.

## 1. 새 Apps Script 프로젝트 만들기

1. https://script.google.com 접속 (구글 계정 로그인)
2. "새 프로젝트" 클릭
3. 기본으로 열려 있는 `Code.gs`의 내용을 전부 지우고, 이 폴더의 `Code.gs` 내용을 그대로 붙여넣기
4. 상단 프로젝트 이름을 "ffe-ose-backend" 등으로 변경 (선택)

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 파란색 **배포(Deploy)** 버튼 클릭 → **새 배포(New deployment)**
2. 톱니바퀴 아이콘 클릭 → **웹 앱(Web app)** 선택
3. 설정:
   - **실행 계정(Execute as)**: 나 (본인 구글 계정)
   - **액세스 권한(Who has access)**: **모든 사용자(Anyone)** ← 반드시 이걸로 설정해야 팀원들이 로그인 없이 접근 가능
4. **배포(Deploy)** 클릭
5. 처음 배포할 때 권한 승인 화면이 뜨면 본인 계정으로 승인
6. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/xxxxx/exec` 형태)을 복사

## 3. 웹페이지 코드에 연결하기

복사한 URL을 프로젝트의 `src/api.js` 파일 맨 위 `APPS_SCRIPT_URL` 값에 붙여넣으세요.

```js
export const APPS_SCRIPT_URL = "여기에_복사한_URL_붙여넣기";
```

## 4. 코드를 수정했을 때

`Code.gs`를 수정한 뒤에는 배포를 새로 해야 반영돼요.
**배포 → 배포 관리 → 연필(수정) 아이콘 → 새 버전 → 배포** 순서로 진행하면 URL은 그대로 유지되고 코드만 최신으로 반영됩니다.

## 참고 / 한계

- 스크립트 속성은 값 하나당 최대 9KB, 전체 500KB까지만 저장돼요. 프로젝트가 많아지고 품목이 아주 많아지면 한계에 부딪힐 수 있어요 — 그때는 저장 방식을 구글 시트 기반으로 바꿔야 합니다. 지금 단계에서는 충분합니다.
- "액세스 권한: 모든 사용자"로 설정하면 이 URL을 아는 사람은 누구나 데이터를 읽고 쓸 수 있어요. 회사 내부용으로만 URL을 공유하세요.
